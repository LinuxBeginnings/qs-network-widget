# qs-network-widget

**Status: alpha.** This is early, untested code under active development. Expect
breakage, missing features and breaking changes without notice. Nothing here is
ready for a production desktop.

A [Quickshell](https://quickshell.org/) (Qt6 / QML) network control panel that
opens from the Waybar network module as a flyout menu. It is built
**specifically for [Hyprland-Dots](https://github.com/LinuxBeginnings/Hyprland-Dots)**
and depends on that project's layout, theming pipeline and helper scripts. It is
not a general-purpose standalone widget and is not packaged or supported
outside that setup.

## What it does

- **Wi-Fi**
  - Lists available wireless networks with signal strength.
  - Connects to a network from the list.
  - Marks the network currently in use.
- **Bluetooth**
  - Lists paired devices.
  - Shows connection state, signal strength (RSSI) and battery level where
    BlueZ reports them.
  - Connects and disconnects devices.
- **Radio control**
  - Wi-Fi on/off and Bluetooth on/off toggles.
  - Airplane mode, which soft-blocks all radios through `rfkill`.
- **Throughput graphs**
  - Live read/write (RX/TX) rate display for the active interfaces.
- **Theming**
  - Colours are pulled from the wallust palette generated by Hyprland-Dots, so
    the panel follows the current wallpaper like the rest of the desktop.

## Repository layout

- `src/quickshell/` — the widget itself: QML components, services and the
  colour/theme loader.
- `src/wallust/` — wallust template and config used to emit the palette the
  widget reads.
- `template/` — early LLM-generated sketches kept as a design reference only.
  This code is **not tested and not wired up**. It shows roughly where the
  project is heading; the real implementation in `src/` supersedes it and is
  expected to diverge heavily.

## Requirements

- Quickshell (Qt6 / QML)
- NetworkManager (`nmcli`)
- BlueZ (`bluetoothctl`)
- `rfkill`
- wallust, driven by Hyprland-Dots
- A Waybar configuration with a module that launches this panel

## Installation

There is no installer yet. The panel is run directly by Quickshell, and the
wallust template is meant to be installed into the Hyprland-Dots wallust
template directory so the palette is regenerated with the rest of the theme.

Installation instructions will be added once the widget reaches a usable state.

## Theming

Colours come from wallust rather than being hardcoded. Hyprland-Dots already
emits a Quickshell palette through its own wallust template, so the widget is
intended to consume that existing output instead of introducing a second
palette file. When the wallpaper changes, wallust rewrites the palette and the
panel reloads it without a restart.
